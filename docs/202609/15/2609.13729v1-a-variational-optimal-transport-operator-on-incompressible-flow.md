## 摘要
我们提出了变分不可压缩最优传输（VIOT）算子，一种用于摊销式不可压缩密度传输的生成式神经算子。给定一个新的源-目标密度对，VIOT 预测无散度速度场，并通过前馈推理生成完整传输轨迹，从而替代伴随流体求解器和可微模拟基线所采用的、针对每对密度耗时数小时的优化。该系统由三部分组成：一种通过构造保证不可压缩性的流函数或矢量势表示；一个平衡端点精度与流动平滑度的正则化不可压缩传输目标；以及一个将求解摊销到新的密度对和网格分辨率上的傅里叶神经算子骨干。这些组件共同使不可压缩传输成为一个可复用的神经算子，便于支持各类传输过程。此外，其生成能力可泛化到训练分布之外，VIOT 能在实时交互系统中为用户绘制的源-目标对生成不可压缩传输。我们在 2D 和 3D 密度传输基准上展示了 VIOT。2D 与 3D 推演均可在每对数秒内完成，而我们在 2D 对比中的逐实例基线需从头优化每个新对，耗时约为一小时，在线加速约达 10^4 倍。

## Abstract
We present the Variational Incompressible Optimal Transport (VIOT) operator, a generative neural operator for amortized incompressible density transport. Given a new source-target density pair, VIOT predicts a divergence-free velocity field and generates the full transport trajectory by feed-forward inference, replacing the hour-scale per-pair optimization used by adjoint fluid solvers and differentiable simulation baselines. The system consists of three components: a stream-function or vector-potential representation that enforces incompressibility by construction, a regularized incompressible transport objective that balances endpoint accuracy and flow smoothness, and a Fourier Neural Operator backbone that amortizes the solve across new pairs and grid resolutions. Together, these components make incompressible transport a reusable neural operator that facilitates various transport processes. Further, the generative capability extends beyond the training distribution, with VIOT producing incompressible transports for user-drawn source-target pairs in a real-time interactive system. We demonstrate VIOT on 2D and 3D density-transport benchmarks. Both 2D and 3D rollouts complete in seconds per pair, while per-instance baselines in our 2D comparisons optimize each new pair from scratch and require on the order of an hour, a roughly $10^4\times$ online speedup.

## 2. 方法论

### 2.1 核心思想
学习一个算子 $\theta$，输入当前密度 $\rho_t$、目标密度 $\rho_1$、归一化时间 $t$，输出流函数（2D）$\psi_\theta$ 或矢量势（3D）$\boldsymbol{\Psi}_\theta$，经谱 curl 得到**构造性无散度速度场**，再通过可微数值平流生成完整轨迹。训练时**仅用端点对**，无需预计算监督轨迹。

### 2.2 连续型目标（式 8）
$$\min_\theta \mathbb{E}_{(\rho_0,\rho_1)}\left[\mathcal{A}_{\alpha,\beta}[\rho, v_\theta] + \gamma D(\rho_1^{\text{pred}}, \rho_1)\right]$$
- 约束：连续性方程 $\partial_t \rho_t + \nabla\cdot(\rho_t v_\theta)=0$，初值 $\rho_0$；
- 作用量 $\mathcal{A}$ 包含**动能项** $\frac{\alpha}{2}\rho_t\|v\|^2$（Benamou–Brenier 型输运代价）与**耗散项** $\beta\|\nabla v\|_F^2$（等价于涡量平方积分，控制光滑度）；
- 终端代价 $D$ 用平方 $L^2$ 距离，替代硬端点约束；
- **Remark 1（端点可行性障碍）**：无散度流的流映射保持体积，故 $\rho_t$ 的每个超水平集体积不变，精确端点匹配要求源与目标的密度值分布相等（强于总质量相等）。因此必须采用有限终端惩罚，形成"精度–正则化"权衡。

### 2.3 硬不可压缩参数化（第 4.2 节）
- **2D**：$v_\theta = \nabla^\perp \psi_\theta = (\partial_y\psi_\theta, -\partial_x\psi_\theta)$，恒满足 $\nabla\cdot(\nabla^\perp\psi)\equiv 0$；
- **3D**：$v = \nabla\times\boldsymbol{\Psi}$，恒满足 $\nabla\cdot(\nabla\times\boldsymbol{\Psi})\equiv 0$；
- **谱 curl**：在 Fourier 域解析求导并施加低通掩码 $M(k)=\mathbb{1}[\|k\|\le k_{\max}]$，如 2D 的 $\hat v_k = 2\pi i(k_y M\hat\psi_k, -k_x M\hat\psi_k)$。优点：(1) 带限场上导数是**精确的**，无有限差分截断误差；(2) 截断 $k_{\max}$ 提供有原则的平滑度控制（默认 0.25 cycles/sample，Font 2D 用 0.0625）；
- 该表示只覆盖零均值螺线分量，不含独立均匀流分量。

### 2.4 网络架构（第 4.3 节）
- **骨干**：Fourier Neural Operator（FNO），选择理由：第一层即有全局感受野、输出天然光滑、权重按 Fourier 模态索引（不依赖网格尺寸）→ 支持跨分辨率执行；
- **输入编码**：$\rho_t$ 与 $\rho_1$ 沿通道拼接为 2 通道输入，逐点卷积升维；时间 $t$ 经正弦位置编码 + 小 MLP 得到条件向量，通过 **FiLM** 广播到每层；
- **FNO 层**：谱分支 $S(z)=\mathcal{F}^{-1}[W\cdot\Pi_{n_{\text{modes}}}\mathcal{F}(z)]$（截断最低 $n_{\text{modes}}$ 个模态、通道维矩阵乘）+ 局部 1×1 卷积分支，输出 $z_{\text{out}} = z + \sigma(\text{GN}(\text{FiLM}_t[S(z)+W_{\text{loc}}z]))$；
- **输出头**：两层逐点 MLP → 单通道 $\psi_\theta$（2D）或三通道 $\boldsymbol{\Psi}_\theta$（3D），再经固定（非学习）的谱 curl 与带宽截断。

### 2.5 训练与推理（第 4.4 节）
- **Rollout 训练**：在 $K=10$ 步上展开平流并反向传播，每步重新查询 $f_\theta(\rho_{t_k}, \rho_1, t_k)$；2D 用无限 MacCormack + 中点半拉格朗日回溯，3D 用量化实现单次半拉格朗日回溯 + 冻结速度；负密度截断为 0，可选质量重归一化；
- **离散损失**：$\mathcal{L}_h = \alpha_h K_h + \beta_h E_h + \gamma_h D_h$，其中 $K_h$ 为动能（无 1/2 因子）、$E_h$ 为有限差分涡量平方、$D_h$ 为带缩放 $s$ 的终端均方误差（2D 单位质量 $s=G$，3D 峰值归一化 $s=1$）；
- **关键细节**：3D 最终训练阶段设 $\alpha_h=0$，仅保留终端匹配 + 耗散正则；部分算子由含动能项的早期阶段初始化；
- **推理**：反复"网络查询 → 平流"共 $K_{\text{infer}}$ 步（默认 50），配合正性截断与质量重归一化；可视化路径可用局部极值限制器或 WENO；
- **动量一致性诊断**：定义 $\boldsymbol{m}=\partial_t v + (v\cdot\nabla)v - \nu\Delta v$，经 Leray 投影得最小 $L^2$ 兼容力 $f_{\text{imp}}=P[\boldsymbol{m}]$，用于评估轨迹与动量方程的兼容程度（训练目标本身不强制动量方程）。
