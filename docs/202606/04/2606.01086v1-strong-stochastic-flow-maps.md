## 摘要
流模型和扩散模型在许多模态中生成高质量样本；然而，在推理过程中，由于需要数值积分底层微分方程，需要进行多次网络评估。流映射通过直接学习微分方程的解映射来缓解这一问题，从而实现少步采样。然而，当前方法仅限于逼近常微分方程（ODE）的解映射。这些方法可用于学习随机微分方程（SDE）的转移核，从而获得一个恢复过程边际分布（弱收敛）而非解路径（强收敛）的解映射。我们提出强随机流映射（SSFMs）作为一种新颖框架，用于学习加性噪声SDE的强解映射，直接将确定性流映射推广到随机设置。此外，引入了布朗运动的多项式近似，并证明其路径收敛。这些结果为扩散模型的解映射提供了无模拟训练目标。我们证明SSFMs在图像生成上优于先前的随机流映射方法，并实现了分子系统的少步采样。

## Abstract
Flow and diffusion models generate high-quality samples in many modalities; however, many network evaluations are required during inference due to numerical integration of an underlying differential equation. Flow maps alleviate this problem by learning the solution map of the differential equation directly, enabling few-step sampling. Yet, current methods are restricted to approximating the solution map of ODEs. These methods can be used to learn the transition kernel of an SDE, thereby obtaining a solution map that recovers the marginal distributions of the process (weak convergence) rather than the solution path (strong convergence). We propose Strong Stochastic Flow Maps (SSFMs) as a novel framework for learning the strong solution map of additive-noise SDEs, directly generalizing deterministic flow maps to the stochastic setting. Further, a polynomial approximation to Brownian motion is introduced and shown to converge pathwise. These results enable a simulation-free training objective for the solution map of diffusion models. We demonstrate that SSFMs outperform previous stochastic flow map methods on image generation and enable few-step sampling of molecular systems.

## 3. 实验设计

### 3.1 数据集与场景

- **非线性SDE toy**：dX<sub>t</sub> = [X<sub>t</sub> − X<sub>t</sub>³]dt + √β<sub>t</sub> dW<sub>t</sub>（模仿方差保持反扩散SDE）。
- **图像生成**：CIFAR-10（32×32）和 CelebA-64（64×64）。
- **分子系统**：
  - Alanine Dipeptide（ALDP，粗粒化5原子，50k样本）。
  - Chignolin（全原子138个原子，10k样本）。

### 3.2 Benchmark与对比方法

- **确定性流映射**：Consistency Training (Song et al., 2023)、Flow Map (LSD / PSD-M / PSD-U, Boffi et al., 2025)、Holderrieth et al. (2026) 的流映射。
- **弱随机流映射**：GLASS (Holderrieth et al., 2026)、Diamond Map (Holderrieth et al., 2026)。
- **扩散基线**：用于分子系统的标准去噪扩散模型。
- **指标**：FID（图像）、PMF平方误差/JS散度（ALDP）、Toroidal W<sub>2</sub> / tICA W<sub>2</sub>（Chignolin）。

### 3.3 结果概述

- **非线性SDE**：随着多项式阶数 N 增加，强误差降低；16步时流映射能准确粗化动力学。
- **图像生成**：SSFM在CIFAR-10上2步FID=4.93，4步=3.49，优于弱随机流映射，与最优确定性流映射竞争；在CelebA-64上类似。
- **分子系统**：
  - ALDP：SSFM在2步时PMF误差0.235（扩散基线的16.7），在100步达0.067（接近1000步扩散的0.058），实现10倍NFE降低。
  - Chignolin：SSFM在低步数（1-4步）大幅优于扩散，多步时趋于一致。

## 6. 主要结论与发现

1. SSFM成功将确定性流映射推广到随机设置，学习加性噪声SDE的强解映射，实现路径级一致性。
2. 布朗运动多项式近似具有良好理论性质（路径收敛、独立高斯系数、封闭陈关系），且仅需少量系数（N=3）即可达到满意性能。
3. 所提出的自蒸馏训练目标免于模拟，可高效训练。
4. 在图像生成（CIFAR-10、CelebA-64）上，SSFM优于现有弱随机流映射，并与顶级确定性流映射可比，甚至在一些步数上超越。
5. 在分子构象采样（ALDP、Chignolin）上，SSFM可实现**1-2步NFE**的准确采样，大幅提升效率，并在多步极限下匹配扩散模型性能。

## 7. 优点

- **理论创新**：首次提出学习SDE强解映射的通用框架，具有切向条件和半群条件的严格理论支撑。
- **布朗多项式近似**：提供独立高斯系数和封闭陈关系，便于神经网络输入和半群损失实现，且收敛性有证明。
- **免模拟训练**：利用扩散模型的条件得分可解析构造真实漂移，使得训练无需数值求解SDE，高效可扩展。
- **少步采样性能突出**：尤其在分子系统上，1-2步即达到扩散模型上百步的精度，极大降低推理成本。
- **代码开源**：提供了GitHub仓库，便于复现和扩展。

## 8. 不足与局限

- **适用范围**：当前框架仅针对加性噪声SDE（扩散系数仅依赖时间）。扩展至状态依赖噪声（一般SDE）需借助更复杂的粗糙路径理论，论文仅提及可能但未实现。
- **多项式截断误差**：阶数N需作为超参数调节，实验显示N=3足够，但未详细探索N对更大规模任务的影响。理论上N需足够大以保证收敛，但过大会增加输入维度。
- **图像实验规模**：仅测试了CIFAR-10和CelebA-64（32/64分辨率），未在更高分辨率（如256×256 ImageNet）评估，与当前最佳扩散模型的差距尚不明确。
- **与弱随机流的对比**：主要侧重于生成质量指标（FID），未深入比较路径一致性（如强误差）在下游任务（如时间序列预测、奖励对齐）中的实质优势。
- **计算成本**：训练时需同时计算小步匹配和蒸馏损失，且需要EMA目标网络，训练开销可能高于简单一致性模型。

- **基线完整性**：图像任务中缺少与最新少步SDE采样器（如DPM-Solver、DEIS）的直接对比（虽然这些方法仍属于数值积分而非流映射）。
