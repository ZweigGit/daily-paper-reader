## 摘要
随机过程的原则性回归是一个长期挑战，与科学反问题有深层联系。我们提出了流退火后验采样（FAPS），据我们所知，这是第一个统一随机过程回归和偏微分方程反问题的函数空间后验采样框架。基于预训练的函数空间流匹配先验，FAPS能够从稀疏且有噪声的观测中进行似然引导的后验推断，支持可变的查询离散化，并避免显式的先验密度评估。其朗之万校正使用低秩协方差预条件器，以利用跨离散化的主导函数空间相关性。在高斯和非高斯随机过程回归基准以及各种偏微分方程反问题中，FAPS生成具有准确不确定性量化的连贯后验样本，显著优于现有函数回归基线，并且在偏微分方程含噪反问题中达到与基于扩散的后验采样器相当或更好的性能，同时降低了测试时采样成本。

## Abstract
Principled regression for stochastic processes is a long-standing challenge with deep connections to scientific inverse problems. We introduce Flow Annealing Posterior Sampling (FAPS), to our knowledge the first function-space posterior sampling framework that unifies stochastic-process regression and PDE inverse problems. Built on pretrained function-space flow-matching priors, FAPS enables likelihood-guided posterior inference from sparse and noisy observations, supports variable query discretizations, and avoids explicit prior-density evaluation. Its Langevin correction uses a low-rank covariance preconditioner to exploit dominant function-space correlations across discretizations. Across Gaussian and non-Gaussian stochastic-process regression benchmarks and diverse PDE inverse problems, FAPS produces coherent posterior samples with accurate uncertainty quantification, significantly outperforming existing functional regression baselines and achieving competitive or better PDE noisy inverse performance than diffusion-based posterior samplers while reducing test-time sampling cost.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- FAPS建立在预训练的函数空间流匹配先验（Operator Flow Matching, OFM）之上。它通过一个退火过程进行后验推断：样本由学习到的流传输，由观测似然通过朗之万动力学校正，并在退火水平之间重新桥接。
- 流程：从参考高斯测度γ采样 \(u_0\)，通过OFM概率流 \( \Phi_{0\to1}^\theta \) 传输到目标过程 \(u_1\)。给定观测y，FAPS冻结先验，迭代执行“流传输→朗之万校正→重新桥接”直到 \(t_K=1\)，得到后验样本。

### 关键技术细节
- **函数空间流匹配先验**：
  - 使用独立耦合流匹配目标训练速度场 \(v_\theta\)，参数化为神经算子。
  - 定义噪声内插路径：\(u_t = t u_1 + (1-t)u_0 + \sigma_{\min}\xi\)，条件速度 \(v_t(u_t|u_0,u_1)=u_1-u_0\)。
  - 训练损失：\(L_{FM}(\theta) = E[\|v_\theta(t,u_t) - (u_1-u_0)\|^2_U]\)。
- **统一后验公式**：
  - 观测模型：\(y = A(u_1) + \epsilon\)，其中 \(A\) 是任务依赖的观测算子。
  - 对于函数回归：\(A = P_\Omega\)（点观测掩码）。
  - 对于PDE反问题：\(A = P_\Omega G_\phi\)，\(G_\phi\) 是预训练的神经算子映射（如FNO替代PDE求解器）。
- **流退火后验采样**：
  - 定义退火调度 \(0 = t_0 < t_1 < \cdots < t_K = 1\)。
  - 给定时刻 \(t_k\) 的桥状态 \(u_{t_k}\)，通过OFM传输到端点得到锚点 \(\hat{u}_k = \Phi_{t_k\to1}^\theta(u_{t_k})\)。
  - 围绕锚点做局部高斯逼近：\(p(u_1|u_{t_k}) \approx N(\hat{u}_k, \lambda_k^2 C_X)\)，其中 \(\lambda_k = \max(\lambda_{\min}, \lambda_{\text{scale}}(1-t_k))\)。
  - 执行L步朗之万校正（协方差预条件）：
    \[
    u_1^{(\ell+1)} = u_1^{(\ell)} + \eta \left[ -\frac{u_1^{(\ell)} - \hat{u}_k}{\lambda_k^2} + C_X \nabla_{u_1} \log p(y|u_1^{(\ell)}) \right] + \sqrt{2\eta} \zeta^{(\ell)}, \quad \zeta \sim N(0, C_X)
    \]
  - 校正后得到干净样本 \(u_k^{\text{clean}}\)，然后重新桥接到下一退火水平：
    \[
    u_{t_{k+1}} = t_{k+1} u_k^{\text{clean}} + s(t_{k+1}) \xi_{k+1}, \quad \xi \sim N(0, \Sigma_0^X)
    \]
  - 重复直到 \(t_K=1\)，得到近似后验样本。
- **低秩协方差预条件**：
  - 从预训练先验的无条件样本中离线计算经验协方差 \(C_X\)。
  - 使用低秩近似：\(C_X = Q_r \Lambda_r Q_r^\top + \sigma_{\text{res}}^2 I\)。
  - 该预条件器捕获目标过程的主导相关性，在稀疏观测下传播似然梯度信息到未观测区域。
